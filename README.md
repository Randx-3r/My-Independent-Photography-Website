## Overview

My website is a sleek, modern digital showcase engineered to highlight fine-art photography through an elevated visual experience. Built with a dark, high-contrast theme and clean, borderless grids, the site allows vibrant imagery to stand out effortlessly while maintaining high-resolution clarity across both desktop and mobile screens. 

Visitors can easily navigate organized collections—ranging from candid street portraits to dramatic natural landscapes—and access an integrated contact portal that makes reaching out for bookings simple and direct. Have fun and enjoy the site

---

## Features

 **Interactive Gallery & Sub-Collections:** Explore curated photo categories featuring expandable dropdown details, detailed descriptions, and related sub-gallery imagery.
 **Responsive Design:** Fully optimized layouts utilizing modern CSS Flexbox and Grid to look stunning on screens of all sizes.
**Modern Contact Portal:** Styled input forms equipped with focus states and smooth transitions for a seamless user experience.
**Live Deployment:** Hosted and version-controlled via GitHub Pages.
